# 旦夕桌面端迁移计划

## 原则

- 新桌面端与现有 Flutter 客户端并行开发，不直接修改或替换移动端。
- 同一套 Svelte 前端同时支持 Tauri 和浏览器部署，通过 transport 适配层切换调用方式。
- Rust 业务核心由桌面端与 Web API 网关共同复用，避免维护两套认证和解析逻辑。
- 优先完成可验证的纵向功能链路，再扩大页面覆盖范围。
- 不机械翻译 Dart 文件；先提取接口契约、状态和失败路径，再按新架构实现。
- 账号、密码、JWT 和 Cookie 始终停留在 Rust 安全边界内。
